- [VoucherController.php](./VoucherController.php#L9) declares `VoucherController`, `VoucherController::download()`.

## Invariants

- `BookingController::store` requires a case-insensitive hexadecimal key in the `8-4-4-4-12` UUID shape. The server accepts other UUID versions alongside the v4 keys generated by checkout. Clients should reuse the exact header value on retry. Missing or malformed keys produce HTTP 422. [Header validation](./BookingController.php#L29) · [Checkout key generator](../../../../../../frontend/src/components/booking/BookingForm.tsx#L756).
- Booking creation returns HTTP 201 for a new booking and 200 for an accepted replay. The JSON contains `data`, an explicit `price_changed` flag that is false on replay, and `payment` when the action returns payment details. [Response mapping](./BookingController.php#L53).
- `TravelerBookingController::show` rejects access when the booking belongs to another traveler. [Ownership check](./TravelerBookingController.php#L51).

## Side Effects

- `BookingController::store` delegates reservation and payment initialization to `CreateBookingAction`. `TravelerBookingController::cancel` delegates cancellation to `CancelBookingAction`. `VoucherController::download` resolves an owner-scoped PDF and serves it as an attachment. [Booking dispatch](./BookingController.php#L53) · [Cancellation](./TravelerBookingController.php#L69) · [Voucher](./VoucherController.php#L26).
